# ИИ-наставник: серверная функция

Кнопка «Объясни по-другому» появляется в заданиях только после того, как эта функция развёрнута и её адрес записан в `js/config.js`. Ключ доступа к языковой модели хранится только на сервере и никогда не попадает в код сайта.

## Что делает функция

1. Принимает с сайта: правило темы, алгоритм, задание, верный ответ, ответ ученика, тип ошибки и проверенный разбор из банка.
2. Просит языковую модель переформулировать объяснение с жёсткими ограничениями (только данное правило, обязательно назвать верное написание, 2–4 предложения).
3. Проверяет ответ модели (длина, наличие верного написания). Сайт повторно проверяет ответ (`js/core/ai.js`): ошибочное написание не может быть названо верным. При любой неудаче ученик видит проверенный текст.
4. Ограничивает частоту запросов и принимает их только с адреса сайта.

Модель не решает, верен ли ответ ученика: это делает детерминированная проверка Орфозора.

## Развёртывание (Supabase)

```bash
supabase functions new orfozor-tutor        # скопировать сюда index.ts
supabase secrets set ANTHROPIC_API_KEY=...  # ключ доступа к модели
supabase secrets set ALLOWED_ORIGINS=https://0011nvg.github.io
supabase functions deploy orfozor-tutor --no-verify-jwt
```

Затем в `js/config.js` указать адрес функции, например
`aiEndpoint: 'https://<проект>.supabase.co/functions/v1/orfozor-tutor'`.

## Персональные данные

В запросе нет имени, кода участника и истории ученика — только текст одного задания и ответ на него. Это важно учесть в описании исследования: внешнему сервису передаются лишь обезличенные учебные фрагменты.

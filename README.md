# ОрфоЗор AI — интерактивный прототип

Статический рабочий SPA-прототип образовательного сервиса для 5–6 классов. Открывается локально без сборки и внешних библиотек.

## Как запустить

1. Распаковать архив.
2. Открыть `index.html` в современном браузере.
3. Для полного поведения download/CSV лучше запустить локальный сервер: `python -m http.server 8000` в папке проекта и открыть `http://localhost:8000`.

## Что реализовано

- Главная с интерактивным примером «найди опасное место».
- Стартовая диагностика, которая проверяет разные этапы действия, а не только выбор буквы.
- Адаптивный тренажёр с четырьмя ступенями: ЗАМЕЧАЮ → РАСПОЗНАЮ → ОБЪЯСНЯЮ → ПРИМЕНЯЮ.
- Трёхуровневые подсказки и раздельный учёт ответов с/без помощи.
- «Паспорт орфографической зоркости».
- Кабинет ученика.
- Кабинет учителя, страница класса и профиль ученика.
- «Создать персональный тренажёр» с обязательной проверкой учителем перед назначением.
- Библиотека орфограмм.
- Исследовательская аналитика и экспорт обезличенного CSV.
- Методическая база с отделением источниковых положений от технологических решений.
- Полностью адаптивная вёрстка, клавиатурный фокус, нецветовые сигналы правильности.

## Информационная архитектура

Главная → Диагностика → Результат → Персональная тренировка → Паспорт → Кабинет ученика.

Учитель → Обзор класса → Класс → Профиль ученика → Создание тренажёра → Проверка → Назначение.

Сквозные разделы: Библиотека орфограмм, Методическая база, Исследовательская аналитика, О проекте.

## Сценарий ученика

1. Нейтральная стартовая диагностика.
2. Фиксация типа затруднения: обнаружение / распознавание / алгоритм / применение.
3. Формирование короткой персональной тренировки.
4. Мгновенная содержательная обратная связь.
5. Подсказки от направляющего вопроса к почти готовому способу действия.
6. Повышение уровня при устойчивом самостоятельном успехе.
7. Возврат к предыдущей операции при затруднении.
8. Перенос навыка в редактирование и контекст.
9. Обновление «паспорта зоркости».

## Сценарий учителя

1. Видит агрегированную картину класса.
2. Открывает профиль ученика и карту затруднений.
3. Принимает или меняет рекомендацию системы.
4. Выбирает тему, этап, тип задания, количество и сложность.
5. Получает предварительный вариант.
6. Редактирует / заменяет / удаляет задания.
7. Обязательно подтверждает проверку перед назначением.

## Логика адаптации (демо)

- Ошибка на уровне 1 → повтор задания на обнаружение опасной позиции.
- Ошибка на уровне 2 → сравнение и классификация.
- Ошибка на уровне 3 → алгоритм + подсказка.
- Успех без подсказок и с первой попытки → переход к более высокой ступени.
- Два устойчивых самостоятельных успеха → добавление более сложной задачи по теме.
- Две и более попытки / две подсказки → вставка более доступного задания до продолжения маршрута.

## Диагностика

Демо использует задания на:

- обнаружение опасного места;
- распознавание условия правила;
- выбор написания;
- смысловую классификацию ПРЕ-/ПРИ-;
- соединительные гласные;
- редактирование ошибки;
- короткое объяснение решения своими словами.

## Модель «Паспорта орфографической зоркости»

Поля: обнаружение, распознавание, применение правила, самоисправление, перенос в текст, повторяющиеся паттерны, освоенные темы, темы в работе, скорость, серия занятий и рекомендация следующего педагогического действия.

## Типы заданий в продуктовой модели

«Найди опасное место», «Орфографический детектор», «Почему здесь опасно?», «Выбери алгоритм», «Проверочное слово», «Орфографическая дуэль», «Редактор», «Лишнее слово», «Собери правило», «Орфографический прогноз», «Мини-диктант», «Объясни ИИ», «Исправь самого себя», «Смешанный вызов».

В демо полностью интерактивны базовые механики: поиск буквы, выбор, редактор, объяснение, адаптивный переход.

## Структура данных

```text
Student(id, class_id, anonymous_code, interests?)
Class(id, name, teacher_id)
Orthogram(id, title, approved_rule, source_ref)
TaskTemplate(id, orthogram_id, skill_stage, task_type, difficulty, answer_schema)

```

## Mastery score — технологическое решение прототипа

Примерная формула интерфейсного индекса: точность 30% + самостоятельность 20% + первая попытка 15% + стабильность 15% + отложенное повторение 10% + перенос в новый контекст 10%.

Это не утверждение из загруженных пособий, а продуктовая гипотеза. Для педагогического исследования веса необходимо валидировать на данных.


## Что нельзя честно извлечь из предоставленных пособий

В доступном тексте пособий не найдено отдельного определения термина **«орфографическая зоркость»**, теоретического описания её компонентов/механизмов или авторской периодизации этапов формирования орфографического навыка. Поэтому прототип **не придумывает и не приписывает авторам** такие положения. Четыре ступени «Замечаю → Распознаю → Объясняю → Применяю» и пооперационная диагностическая модель взяты из технического задания проекта и помечены как проектные решения.

## Методическая опора на предоставленные материалы

**О. В. Узорова, Е. А. Нефёдова, «Русский язык. Правила и упражнения. 6 класс» (2014):** использованы правила и структура упражнений по КОС-/КАС-, ГОР-/ГАР-, Ы/И после приставок, ПРЕ-/ПРИ-, соединительным О/Е. В пособии регулярно встречается цепочка «вставить / выделить морфему → объяснить → разобрать / составить предложение → исправить ошибки».

**Л. Г. Ларионова, «Русский язык. Орфография. Рабочая тетрадь. 6 класс» (2014):** учтены механики сортировки слов по орфограммам, заполнения таблиц «правило — пример», графического объяснения выбора, словарных диктантов, работы с текстом, смысловой группировки ПРЕ-/ПРИ- и смешанных тренировочных тестов.

Прототип не копирует большие фрагменты пособий и не использует ИИ как источник орфографической нормы.

## Wireframe

Встроен в раздел «Методика» внутри самого прототипа: три схематичных ключевых экрана — ученик, тренажёр, учитель.

## Ограничения демо

- Нет backend и авторизации.
- «ИИ» моделируется прозрачными правилами адаптации и шаблонной генерацией.
- Данные сохраняются только в `localStorage` браузера.
- Для продакшена нужны: серверная БД, ролевая модель, журнал согласования контента, реальный генератор с retrieval из утверждённой базы и педагогическая валидация mastery score.

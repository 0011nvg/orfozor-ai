# Орфозор

Интеллектуальный тренажёр орфографии русского языка для 5–6 классов: адаптивная модель знаний (BKT), диагностика ошибок, объяснимые рекомендации, интервальное повторение. Для учителя — методические паспорта тем, ключи, ссылки на подборки и печатные листы; для исследователя — срезы, сравнение групп и статистика.

Сайт: https://0011nvg.github.io/orfozor-ai/ (технический адрес не менялся; публичное название — «Орфозор»).

## Что внутри

- **33 темы** (24 — 5 класс, 9 — 6 класс), сверенные с Федеральной рабочей программой по русскому языку; **413 заданий** девяти типов: вставка буквы, выбор, несколько ответов, распределение, поиск орфограммы, выделение корня, поиск ошибок, расстановка запятых, запись слова.
- Маршрут темы: **правило → тренировка → проверка себя → повторение**. Отдельно — диагностика по классу и смешанная практика («сначала узнай правило, потом реши»).
- **Модель знаний** (байесовское отслеживание знаний) подбирает задания и оценивает освоение каждой темы; **рекомендации** объясняют, что делать дальше и почему; ошибки классифицируются по 8 типам.
- **Исследование**: входной и итоговый срезы (параллельные формы), обезличенные файлы участников, критерии Уилкоксона и Манна — Уитни, корреляция Спирмена, CSV.
- **ИИ-наставник** «Объясни по-другому» — генеративная модель с проверкой ответа; включается после развёртывания `server/ai-tutor` (см. README там).
- Режим интерактивной доски и режим удобного чтения.
- Прогресс хранится только в браузере; его можно сохранить в файл и перенести.
- Работает офлайн после первого открытия (service worker).

Методика и обоснование решений — в [docs/METHODOLOGY.md](docs/METHODOLOGY.md), аудит прежней версии и перечень изменений — в [docs/AUDIT.md](docs/AUDIT.md).

## Запуск локально

Сайт статический, сборка не нужна. Из-за ES-модулей открывать нужно через локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как добавить задание

Задания пишутся компактно (см. `js/content/build.js`):

```js
gap('заг[о/а]рать', 'Корень -гор- без ударения: О.')          // первый вариант в скобках — верный
gap('опас[/т]ный', 'Опасный — опасен: Т не пишется.')         // пустой вариант = «ничего не писать»
fix('Мы *прилажили|приложили* колышек.', 'Перед Ж пишется О.') // *ошибка|исправление*
punct('Котёнок был маленький, но смелый.', 'Перед НО запятая.') // верные запятые прямо в тексте
```

После правок обязательно запустить тесты.

## Тесты

```bash
npm ci
npm test                                   # 40 проверок: банк и срезы, словарь, ответы, прогресс, модель, статистика
python3 tests/e2e/run_e2e.py http://localhost:8000/   # нужен Chrome и Playwright для Python
```

`npm test` проверяет каждое задание: структуру, решаемость эталонным ответом, отсутствие второго верного варианта, наличие верных написаний в русском словаре Hunspell и то, что неверные варианты — действительно ошибки. Сквозной тест проходит **все** задания через интерфейс в браузере и проверяет основные сценарии ученика и учителя.

## Публикация

GitHub Actions (`.github/workflows/deploy.yml`) запускает тесты на каждый pull request и публикует сайт на GitHub Pages только после слияния в `main`.
